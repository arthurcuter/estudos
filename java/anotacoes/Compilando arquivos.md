Para compilar em Java, primeiro é necessário compilar o código-fonte .java que escrevemos, fazendo ele se tornar um Bytecode, que será lido pela Java Virtual Machine:
- Digite "javac nomeDoArquivo.java"
"javac" se diz referente ao Java Compiler, compilador do Java
- Um arquivo .class será criado, ele é o Bytecode
- Digite "java nomeDoArquivo", sem a extensão .java, e então o arquivo será executado pela JVM.

Em versões mais recentes do Java, também é possível executar diretamente, utilizando "java nomeDoArquivo.java".
