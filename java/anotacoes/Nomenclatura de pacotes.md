Os pacotes, por convenção, devem começar com a URL do site invertida + o nome do projeto + subprojeto. Tudo isso separado por pontos e tudo minúsculo, sem outros caracteres.

	Exemplo:
	 academy.devdojo.maratonajava.introducao
	 
Cada ponto diz respeito a uma pasta. Ou seja, no exemplo, é como se ele tivesse criado uma pasta chamada academy, dentro dela uma chamada devdojo, dentro dela uma chamada maratonajava, e por fim dentro dessa uma chamada introdução. 

Toda classe dentro de pacotes começa com 

	package nome.do.pacote

No topo do código, isso indica onde ela está localizada, e obrigatoriamente está na primeira linha do código.
