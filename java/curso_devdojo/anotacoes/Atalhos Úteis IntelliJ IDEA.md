
| Windows | MacOS   |
| ------- | ------- |
| Alt     | Option  |
| Ctrl    | Command |

- Ctrl + Shift + F10
	Executa o código;
- Ctrl + D
	Duplica a linha;
- Ctrl + Y
	Exclui a linha;
- Ctrl + /
	Comenta a linha;
- Ctrl + Shift + /
	Comenta o bloco;
- Ctrl + Alt + L
	Reformatar o código;
- Alt + Insert
	Gerar código.
