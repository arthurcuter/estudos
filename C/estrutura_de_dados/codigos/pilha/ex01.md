
Escrever uma função para a estrutura pilha para resolver cada uma das tarefas a seguir: 
1. Exibir a pilha do topo para baixo;
2. Extrair o elemento abaixo do topo, se possível;
3. Amassar o topo da pilha, isto é, quando for empilhar, se o elemento novo for maior que o elemento do topo, ele vai sobrescrever, se não, apenas empilha;
4. Amassar a pilha, isto é, enquanto o elemento novo for maior que os elementos da pilha, vai amassando;
5. Sobrecarrega a pilha, ou seja, quando for empilhar um elemento, empilha duas vezes. Se não der pra inserir o segundo, insere apenas o primeiro;
6. Modificar o método empilha para preservar pelo menos uma posição da pilha (construir empilha2 e esta_cheia2);
