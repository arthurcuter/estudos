# Estudos

Repositório onde guardo minhas anotações e códigos de estudo: matérias da faculdade (ADS na Fatec Ipiranga), cursos online e coisas que estudo por conta própria.

Não são projetos prontos. É o registro do que fui aprendendo, por isso tem de tudo um pouco, do básico ao mais elaborado.

### C / Estrutura de Dados

Implementações em C feitas na disciplina de Estrutura de Dados:

- **Pilha:** implementação com header (`pilha.h`), exercícios e um teste de estouro de pilha
- **Lista ligada** e **lista duplamente ligada:** nós, inserção e remoção no início e no fim
- **Vetor dinâmico:** com ordenação por Quick Sort
- **Recursão:** exemplos usando a pilha de chamadas
- Exercícios iniciais de alocação de memória, funções e tamanho de tipos

### Java

- **curso_devdojo:** anotações e exercícios da Maratona Java do DevDojo (arrays, casting, classes, `this`, varargs, estrutura de pacotes, atalhos do IntelliJ)
- **curso_nelio_alves:** exercícios do curso de Java do Nélio Alves
  - `aula154_excecoes`: tratamento de exceções com exceção personalizada (`DomainException`)
  - `aula168_arquivos`: leitura e escrita de arquivos, gerando um `.csv` de resumo

### Linux

- **fiapFundamentos:** anotações do curso de fundamentos de Linux da FIAP, com foco no uso pelo terminal

### AWS

- **cloud_foundations:** anotações sobre computação em nuvem, redes (firewall, gateways, switch, ACL) e armazenamento (DAS, NAS, SAN)

### Web

Meus primeiros estudos de HTML e CSS:

- **html:** estrutura de uma página, caracteres especiais, áudio, vídeo e SVG
- **html2:** formulários, tabelas, microdados e os elementos `progress` e `meter`
- **intro_css:** primeiros passos com CSS
